# Mente Inquebrantable — Nanatsu Edition

Tracker personal de hábitos, peso y finanzas ambientado en *Nanatsu no Taizai*.
42 rangos de poder, de Twigo al Caos Primordial.

## Uso
- **Web / celular:** abrir el link de GitHub Pages e instalar desde el navegador
  (Android: menú ⋮ → *Instalar app* · iPhone: Compartir → *Agregar a inicio*).
- **PC sin internet:** doble clic en `index.html`.

Los datos se guardan en el navegador de cada dispositivo (no en este repositorio).
Para pasarlos de un dispositivo a otro: *Exportar respaldo* → *Importar respaldo*.

## Archivos
- `index.html` — la app completa
- `niveles.js` — los 42 rangos, eras y escenarios
- `manifest.webmanifest`, `sw.js`, `icons/` — instalación en celular y modo sin internet

Al publicar cambios, subir la versión de `CACHE` en `sw.js` para que el celular se actualice.
